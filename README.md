revpiper takes a systematic review team from extracted data to
manuscript-ready tables and figures, driven by specifications you author
— a data dictionary describing your extraction files, declared assembly
and cleaning, audited manual corrections, and a re-runnable derivation
layer — rather than code you write.

**Status: pre-alpha.** The design is documented in
[`dev/superpowers/specs/`](dev/superpowers/specs/); implementation is
in progress and nothing here is usable yet.
